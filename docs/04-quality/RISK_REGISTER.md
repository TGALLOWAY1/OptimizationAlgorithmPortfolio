# Risk Register

> Forward-looking risks. Severity: Low · Medium · High · Critical. Status: Open · Mitigated · Accepted.
> Last updated: 2026-05-28.

---

## R1 — Unauthenticated, unrate-limited LLM endpoints (cost & abuse)
- **Severity:** High · **Area:** Security / cost · **Status:** Open
- **Description:** All 8 API endpoints are open (no auth, no rate limit) with wide-open CORS; each call spends Gemini credits.
- **Why it matters:** A single exposed instance can be driven to arbitrary spend by any origin.
- **Evidence:** `api/app.py:19`, `pipeline/recommender_api.py:20`; no auth in any `api/*.py`.
- **Mitigation:** API key/token, per-IP rate limit, restricted CORS allowlist before any public hosting.
- **Owner:** unassigned.

## R2 — `debug=True` Werkzeug debugger (RCE if exposed)
- **Severity:** High · **Area:** Security · **Status:** Open
- **Description:** Both Flask apps run `debug=True`, `host=0.0.0.0`; the interactive debugger allows code execution on unhandled errors.
- **Why it matters:** Catastrophic if the app is reachable beyond localhost.
- **Evidence:** `api/app.py:66`, `pipeline/recommender_api.py:105`.
- **Mitigation:** `debug=False` for non-local; gate behind env.

## R3 — Path traversal via unsanitized compare slug
- **Severity:** Medium · **Area:** Security · **Status:** Open
- **Description:** `slug_a`/`slug_b` used directly in a filesystem join; only existence checks limit blast radius.
- **Why it matters:** Could read directories outside the techniques tree.
- **Evidence:** `api/compare.py:37`.
- **Mitigation:** Validate slug format / membership before path use.

## R4 — Executing LLM-generated code without a real sandbox
- **Severity:** Medium · **Area:** Security · **Status:** Open (contained)
- **Description:** The judge's `run_python_code` runs model-supplied Python in a subprocess with the same user, no network/filesystem isolation; import allowlist applies to declared deps, not the executed string.
- **Why it matters:** A malicious/injected artifact could run arbitrary local Python. Contained today: offline eval only, not reachable via HTTP, and content is generated by a trusted model.
- **Evidence:** `pipeline/code_runner.py:91-141`, `pipeline/judge_tools.py:26-39`.
- **Mitigation:** Run in a container/seccomp/nsjail with no network; enforce the allowlist on the executed code too.

## R5 — Prompt injection through user-supplied endpoint inputs
- **Severity:** Medium · **Area:** AI safety · **Status:** Open
- **Description:** `adapt_code`, `math_tutor`, `study_plan`, `recommend` interpolate user text into prompts; the non-tool Gemini path concatenates system+user into one string (no trust boundary).
- **Why it matters:** Users can steer model behavior; outputs feed the UI.
- **Evidence:** `api/adapt_code.py:57-63`, `llm_client.py:91`.
- **Mitigation:** Use the real `system_instruction`, add input guards, validate/escape rendered output.

## R6 — Single-vendor, single-key dependency on Gemini preview models
- **Severity:** Medium · **Area:** Availability · **Status:** Open
- **Description:** Entire runtime depends on three Gemini **preview** models and one API key. Preview models can change/deprecate.
- **Why it matters:** A model rename/deprecation or key issue halts all generation and all API features.
- **Evidence:** `config.json:24-37`, `llm_client.py:85-86`.
- **Mitigation:** Pin/track model availability; reintroduce a provider abstraction fallback (the `LLMProvider` ABC already supports it).

## R7 — Red test suite + no CI
- **Severity:** Medium · **Area:** Quality · **Status:** Open
- **Description:** 6 failing tests and no CI gate; regressions can land unnoticed.
- **Why it matters:** Erodes confidence; the docs claimed green.
- **Evidence:** `docs/03-implementation/TESTING_STRATEGY.md`.
- **Mitigation:** Fix fixtures (Issue #1) + add CI (Debt #9).

## R8 — Topic-retarget drift across code, templates, tests, and docs
- **Severity:** Medium · **Area:** Correctness · **Status:** Open
- **Description:** The optimization→MCTS retarget updated config + schemas but left templates (playground, KG legend), the judge revision prompt, multiple docs, and test fixtures on the old domain.
- **Why it matters:** User-visible wrongness (playground/graph) and contributor confusion.
- **Evidence:** Issues #1, #2, #4, #5, #11.
- **Mitigation:** A single "finish the MCTS migration" sweep across templates/judge/docs/tests.

## R9 — Deploy publishes a placeholder; production has no working features
- **Severity:** Medium · **Area:** Product/deploy · **Status:** Open
- **Description:** The live site is the placeholder; interactive tools need a backend that isn't deployed.
- **Why it matters:** The public-facing artifact doesn't represent the product.
- **Evidence:** `.github/workflows/pages.yml`, `build_site.py:120-123`.
- **Mitigation:** Decide and document the deployment story (Issue #3).

## R10 — Untested orchestration code (`generate.py`, `publish.py` assembly)
- **Severity:** Medium · **Area:** Quality · **Status:** Open
- **Description:** The two scripts that drive generation and publishing have little/no direct test coverage and many broad exception handlers.
- **Why it matters:** Silent failures in the core pipeline.
- **Evidence:** `docs/03-implementation/TESTING_STRATEGY.md` coverage gaps.
- **Mitigation:** Add smoke tests with mocked providers.
